# 問題データ作成プロンプト（コピペ用）

Claude Code 以外の AI チャット（claude.ai、ChatGPT など）で問題データを作るときに使うプロンプトです。
下の「ここから」〜「ここまで」をそのまま貼り付け、最後の【依頼】欄だけ書き換えてください。
Claude Code でこのリポジトリを開いている場合は、スキル `make-cards`
（`.claude/skills/make-cards/SKILL.md`）が使われるので、このプロンプトは不要です。

依頼の書き方の例：

- 「光合成に関する問題データを15問作成して」
- 「以下の内容から問題データを、1問1答と4択で10問作成して」（続けて文章を貼る）
- 「江戸幕府の歴代将軍で、順番当てと組み合わせを中心に8問」

できた CSV はテキストファイル（拡張子 `.csv`、UTF-8）に保存し、アプリの「CSVインポート」で取り込みます。
取り込み前に手元で確かめるなら `node tools/validate-cards.js <ファイル>` を実行してください。

---- ここから ----

あなたは暗記アプリ用の問題データを作る担当です。下の【依頼】に従って問題を作り、
次の仕様どおりの CSV を1つのコードブロックで出力してください。

## 依頼の読み取り

- 題材：【依頼】のテーマ、または貼り付けられた文章。文章が与えられたときは、その文章に書かれた事実だけで作る。
- 問題数：指定が無ければ10問。題材から作れる数が足りなければ水増しせず、作れた数と理由を CSV の後に書く。
- 形式：指定が無ければ題材に合うものを混ぜる（single と choice を中心に、順序があれば ordering、
  対になる用語があれば matching、短い語の暗記なら anagram）。
  呼び方の対応：1問1答＝single、多肢選択・4択＝choice、組み合わせ・対応＝matching、
  順番当て・年代順・手順＝ordering、並べ替え・アナグラム＝anagram。
- 言語：指定が無ければ日本語。

## CSV の仕様

ヘッダ行を必ず付け、列はこの順にする。`id` は常に空欄。

```
id,type,question,choice1,choice2,choice3,choice4,choice5,choice6,answerIndex,answer,explanation
```

| type | choice1〜6 | answerIndex | answer |
|---|---|---|---|
| single | 空 | 空 | 解答（必須）。短く一意に決まるもの |
| choice | 選択肢を2〜6件（基本は4件） | 正解の番号（1起点、1〜選択肢数） | 空 |
| matching | `左:右` を2〜6件。左も右も重複させない | 空 | 空 |
| ordering | 2〜6件を正解の順に並べる。問題文に「古い順に」など何の順かを書く | 空 | 空 |
| anagram | 空。拗音などを1かたまりにしたいときだけ choice1 に `"ファ,イ,ル"` のようなカンマ区切り1件 | 空 | 完成形（必須）。トークンを連結すると一致すること |

- explanation（解説）は全問に1〜2文で、答えの根拠や覚え方を書く。
- matching の値に `:` や `\` を含むときは `\` を `\\`、`:` を `\:` に置き換える（バックスラッシュを先に）。
  例：`開始時刻\:12\:30:Start Time`
- カンマ・ダブルクォート・改行を含む値は `"` で囲み、値の中の `"` は `""` にする。
- 選択肢は表示時にシャッフルされるので、choice の正解位置を気にする必要はない。
- 列数は全行12列に揃える（空の列もカンマで区切る）。

例：

```csv
id,type,question,choice1,choice2,choice3,choice4,choice5,choice6,answerIndex,answer,explanation
,single,日本の初代内閣総理大臣は？,,,,,,,,伊藤博文,1885年に初代内閣総理大臣に就任した。
,choice,日本の最高峰は？,富士山,北岳,奥穂高岳,槍ヶ岳,,,1,,標高3776m。2位は北岳（3193m）。
,matching,国と首都を対応させよ,日本:東京,フランス:パリ,ドイツ:ベルリン,イタリア:ローマ,,,,,ヨーロッパ主要国の首都。
,ordering,日本の時代を古い順に並べよ,鎌倉時代,室町時代,江戸時代,明治時代,,,,,鎌倉（1185年頃〜）→室町→江戸→明治。
,anagram,「ファイル」を並べ替えよ,"ファ,イ,ル",,,,,,,ファイル,拗音はトークンで1かたまりにする。
```

## 内容の確かさ

- 事実として正しいことだけを問う。自信の持てない数値・年号・固有名詞は使わない。
- 時期で変わる事実は、問題文に基準時点を書くか避ける。
- 1問で問うことは1つ。問題文だけで答えが一意に決まるようにする。
- choice の誤答は紛らわしいが明確に誤りのものにし、「すべて正しい」のような選択肢は使わない。
- 同じ事実や同じ問題文を繰り返さない。

出力前に、各行が上の仕様（特に answerIndex の範囲、matching のコロン、anagram の answer、列数）を
満たしているか確認してから出力してください。

【依頼】
（ここに「〇〇に関する問題データを〇問作成して」や、元になる文章を書く）
